# skill-hub

Хаб независимых модулей rules, skills и переносимых ролей. Контракт и команды находятся в README.md.

- modules/ является каталогом. Чтение или редактирование модуля не активирует его политику для хаба.
- Подключаются только выбранные модули. В каждой family допускается один вариант.
- Не добавляй скрытые зависимости между модулями, обязательный трекер или обязательную цепочку ролей.
- Ресурсы скилла размещай внутри его папки. Не дублируй каталог в .agents.
- Служебные скиллы хаба находятся в .agents/skills: hub-modules, hub-create-skill, hub-init-project.
- Реестры проектов, machine-specific paths, Notion URL и credentials не хранятся в модульном каталоге.
- При переработке инструкций меняй только относящийся к задаче текст. Нужные пояснения входят в запрошенное изменение.
- Проверяй modules и presets командой node scripts/hub.mjs validate. Для helper запускай node --test tests/hub.test.mjs.
- Сохраняй изменения пользователя. Внешние действия выполняются только в пределах запроса.
- Не расширяй scope задачи: сохраняй не относящиеся к запросу файлы, инструкции и форматирование. Не делай попутный рефакторинг, переименование или «улучшения». Сопутствующие правки допустимы только когда без них запрошенное изменение не работает; объясни их связь с задачей.
