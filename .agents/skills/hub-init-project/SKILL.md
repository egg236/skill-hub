# Init from the hub

Read `modules/authoring/project-init/skills/init-project/SKILL.md` and the hub `README.md`.
Determine path, actual project state, and needed modules. Do not force a default preset.
Create only the allowed minimal structure and attach the full chosen set via `scripts/hub.mjs`.
Check `status` and report the result. External registries, remotes, Notion, and deployment are not required parts of init.
